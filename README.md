# Library Management System

## Tech Stack
- **Frontend**: React + Tailwind CSS + Framer Motion + React Router + Recharts + Axios
- **Backend**: Node.js + Express.js + SQLite + Sequelize ORM + JWT Authentication

## Setup
1. Clone the repo
2. Run `npm run install-all` (installs root, server, and client dependencies)
3. Copy `.env.example` to `.env` in `/server` and fill values
4. Run `npm run seed` to populate database with sample data
5. Run `npm run dev` to start both frontend (localhost:5173) and backend (localhost:5000)
